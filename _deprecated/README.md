# Deprecated Files

This folder contains files that are no longer used on the live site but are kept for reference.

## Contents

### `neocities.png`
A "Hosted on Neocities" badge from an earlier version of the site. Not referenced anywhere on the current site.

### `templates/`
Page templates used as starting points for creating new content:
- `news_template.html` — Template for news articles
- `event_page_template.html` — Template for event pages
- `guide_template.html` — Template for game guides

These are useful references when creating new pages but are not live pages themselves.

### `old-writings-json/`
Test writing data from before the D1 database migration. These JSON files were used by the old Google Apps Script backend to store writings. All writing data is now managed in the D1 database via `/api/writings`.

### `unlinked-guides/`
Guide pages that exist in the repo but are not linked from any page on the site:
- `support-card-guide.html`
- `uaf-guide.html`

These can be linked from the Guides section of `index.html` when ready to publish.
